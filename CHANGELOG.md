# Changelog

## v0.6.1

First public release of **Later Thoughts**.

### Features
- Named plain-text notes
- Quick Entry
- Manage Notes
- Most-recently-modified ordering
- Timestamp/date/book-page/divider/bullet inserts
- Centered main and management UI
- Tap-outside Insert dismissal
- Kindle keyboard-safe dialog behavior

### Notes
- Public branding changed from the development name to Later Thoughts.
- Existing development-build note storage remains compatible.
